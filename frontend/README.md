# 🎨 GenMedia Frontend Service

Modern React 18 + Vite client styled with Tailwind CSS for media generation studio workflows and Backblaze B2 asset vault inspection.

## 🚀 Development Setup

```bash
# Install dependencies
npm install

# Copy environment file
cp .env.example .env

# Run Vite dev server
npm run dev
```

App will be live at `http://localhost:5173`.
